## 业务背景和价值

在 AI 生图任务中选择 LinkFox 已有词库，使商品套图生成使用敏感词检测与 AI 改写规避、预设词语替换。词库及词条继续在 LinkFox 维护，我方提供选择、任务保存及生图传参能力。

## 需求概述

- 美工版、运营版均覆盖新增、编辑、查看、批量导入、批量修改五个入口；查看只读。
- 敏感词库、替换词库独立选填、各单选；任务只存 ID，名称实时查询，不持久化词库列表。
- 批量导入统一应用本次选择；批量修改分别支持保持不变、设置词库、清空。
- 提交不新增词库可用性拦截；接口失败沿用既有流程，复制重跑继承两个 ID。

本期仅对接 LinkFox 商品套图 V4；不新增词库管理、导入文件逐行词库列、独立文本检测接口、命中明细或改写前后对比，也不新增复制入口或改变任务状态流转。

## 功能需求

### 1. 影响入口与字段展示

五个入口均覆盖美工版、运营版，共十处；可复用组件，各端各入口均需回归。

| 入口 | 默认值与操作 | 应用范围 |
|---|---|---|
| 新建任务抽屉 | 普通新增两项默认不选；复制重跑按第 5.1 节继承来源 ID。均可选择、更换、清空 | 当前新建任务 |
| 编辑任务抽屉 | 按已保存 ID 回显，可更换、清空 | 当前可编辑任务 |
| 查看任务抽屉 | 按已保存 ID 只读回显 | 当前被查看任务 |
| 批量导入弹窗 | 两项默认不选，统一选择 | 本次实际创建的所有任务，含待完善任务 |

位置与样式：

- 新增、编辑、查看抽屉固定放在“LinkFox 子模型”上方；敏感词库在左、替换词库在右，窄屏按此顺序换行。批量入口采用相同顺序及样式，最终嵌入位置按现有弹窗布局核对。A+ 排版重构另提需求。
- 轻量总标题统一为“LinkFox违禁词库”，字号、字重、颜色及下方间距与“LinkFox 子模型”一致；排列为“总标题 → 共用适用范围说明 → 两个字段”。
- 共用说明统一为：“多模型适配：该字段仅 LinkFox 使用；自研、阿里绘蛙忽略此字段。”
- 新增、编辑底部按钮统一为“取消”“保存为待提交”“保存并提交生图”。

| 字段 | 可配置入口的单选框占位文案 | 新增／编辑／查看／导入的灰色说明 | 批量修改的灰色说明 |
|---|---|---|---|
| 敏感词库 | 请选择敏感词库 | 选填，命中的敏感词由 AI 改写规避。 | 命中的敏感词由 AI 改写规避。 |
| 替换词库 | 请选择替换词库 | 选填，命中的词按预设替换词直接替换。 | 命中的词按预设替换词直接替换。 |

标题及占位文案不加“（可选）”。新增、编辑、导入可清空；批量修改先选择操作，“设置词库”时才展示单选框，详见第 4 节。

选择与名称展示规则：

1. 两类词库独立、各最多选择一个；不支持数组或逗号拼接 ID。不自动选中通用词库或唯一候选项。
2. 保留接口返回顺序，默认展示名称；同类重名项辅助展示完整 ID。关联键为“类型 + ID”，不按名称反查、合并或替换。
3. 候选项及已选名称使用黑色，含只读查看；占位、“未选择”及说明使用灰色。
4. 长名称在字段内省略；候选项悬停或键盘定位时，详情浮层展示完整名称及完整 ID，可换行、不截断，不能仅依赖原生 `title`。鼠标展开下拉框不自动展示首项详情浮层。已选字段取得名称后，重新悬停约 300 毫秒或通过 Tab 主动定位时展示详情浮层；选中后及程序自动返回焦点不触发，移开或失焦即隐藏。只读查看采用相同规则。未选择时无详情浮层；已有 ID 但名称未取得时，按第 2 节在行内展示状态及完整 ID，无重复浮层。字段灰色说明仍保留，加载及异常提示按状态表处理。
5. 当前接口未返回渠道、词条数及创建／更新时间，不据此展示或筛选；不额外过滤词条数为 0 的词库。

显示条件：

整组复用各入口现有“LinkFox 子模型”的显示条件，不新增独立判断。

| 启用模型 | 词库区域及 LinkFox 子模型 |
|---|---|
| 仅 LinkFox，或 LinkFox 与其他模型同时启用 | 显示 |
| 未启用 LinkFox | 一起隐藏 |

- 隐藏包括标题、说明、字段及提示，不留空白占位或禁用控件。查看也遵循此规则，即使保存了历史 ID。
- 隐藏不清空已保存 ID 或本次选择；重新显示恢复选择，保存不能因字段未渲染而写成空值。查询时机见第 2 节。
- 批量混选沿用各入口既有子模型显示条件，不另设“任一／全部启用”判断或混选提示。隐藏提交时，导入保留本次选择，批量修改按保持不变，分别见第 3、4 节。

查看抽屉的差异：

复用上述布局、样式和提示，以禁用的单选框保留边框、箭头及禁用背景；不能展开、选择或清空，无保存操作，底部仅“关闭”，右上角仍可关闭。名称及异常按第 2 节状态表展示；允许的查询重试不改变配置或触发生图。

### 2. 实时查询与加载状态

查询时机与范围：

1. 每次打开入口，区域显示时分别查询两类词库；初始隐藏则等本次首次显示再查询，隐藏期间即使有 ID 也不查询。沿用当前账号、业务端及 LinkFox 授权／调用通道，凭证由服务端管理，不跨上下文串用候选列表。
2. 同次打开复用结果，展开下拉框、选择词库、隐藏后重新显示或批量任务行数增加均不重复查询；失败可手动重试。关闭即丢弃结果，再次打开且显示时刷新。不建立词库同步表、定时任务或跨会话持久化缓存。
3. 两类独立加载，一类异常不影响另一类结果、用户选择及其他表单内容。查询期间或失败后不能选择尚未取得的候选项。
4. 隐藏后返回的请求不重新显示区域或改写 ID，可在同次打开复用结果；关闭后的旧请求不得覆盖再次打开的新上下文。

自动分页规则：

1. 每类从 `pageNum=1`、`pageSize=100` 开始，后续页同为 100 条；`hasMore=true` 时自动依次请求下一页，直至 `false`。不因单页不足 100 条提前结束，也不单凭 `total` 推算结束。
2. 每类取齐前保持加载中，取齐后按接口顺序合并展示；两类无需互相等待。不提供用户翻页或滚动加载，展开、滚动只浏览已加载的候选项。
3. `total` 辅助核对完整性；例如 `hasMore=false` 但累计结果少于总数，按加载失败处理。任一页网络失败、超时、业务失败或结构异常同样处理，不展示部分候选项、不据此判定原 ID 缺失。
4. 失败统一使用下表的加载失败提示，不新增分页专属状态；手动重试从该类型第 1 页重新取齐，保留另一类结果及表单内容。响应解析见第 6 节。

统一状态表：

仅在区域显示时适用；名称在对应类型内按 ID 匹配本次完整列表，不用历史名称兜底。

| ID 与查询状态 | 字段展示与操作 |
|---|---|
| 无 ID | 查看始终显示“未选择”，不显示加载、错误或重试；可配置入口显示对应占位、加载中、暂无可选词库或加载失败状态，失败可重试，不自动选择。 |
| 有 ID，正在查询／自动取页 | “正在加载词库名称”及完整 ID，暂不可选择候选项。 |
| 有 ID，完整列表成功且找到 ID | 展示本次返回的名称。 |
| 有 ID，完整列表成功但未找到 ID，含有效空列表 | “词库当前不可选”及完整 ID；可配置入口提示“原词库当前不可选，请重新选择或清空。”，查看提示“当前列表中未找到该 ID。”。不据此断言已删除。 |
| 有 ID，请求失败或分页异常导致未取完整 | “词库加载失败”及完整 ID，提示“词库加载失败，请重试。”并提供重试；不能判为当前不可选。 |

查询、回显和重试均不修改任务 ID；不得自动清空或用同名项替换。只有用户明确更换／清空并保存才改变配置。“选填”不代表可自动省略已有 ID；保存和提交按第 5 节处理。

### 3. 批量导入

1. 在弹窗统一选择，以提交导入时的最终选择为准，将相同的两个 ID 写入本次实际创建的每个任务；不增加导入文件列或逐行输入。
2. 未选择的类型为空，不读取其他任务或上次导入的选择。待完善任务也保留配置，后续编辑按统一规则回显、修改。
3. 沿用既有导入校验、范围、数量限制、任务状态及逐行处理；失败且未创建的行不生成词库配置记录。
4. 先选后隐藏仍保存本次 ID；始终未选择则为空，隐藏不等于清空。

### 4. 批量修改

两个字段分别提供以下操作，默认均为“保持不变”，互不联动；只修改其他任务字段时，两项均保留各任务原值。

| 操作 | 选择要求 | 保存结果 |
|---|---|---|
| 保持不变 | 不选择 | 各任务保留自己的原 ID，不以某个任务的配置覆盖其他任务 |
| 设置词库 | 必须选择本类型一个候选项 | 各任务该类 ID 更新为本次选择 |
| 清空 | 不选择 | 各任务该类 ID 置空 |

“保持不变”不额外展示说明框；“清空”展示对应操作结果提醒，两种操作均保留字段灰色说明。

- 区域显示且选择“设置词库”却未选具体 ID 时，提示选择并阻止本次批量修改；清除设置操作中的临时选项仍属未选完，不等于“清空”。这属于表单完整性校验，不是生图前词库可用性校验。
- 区域隐藏时两项均按“保持不变”提交，不执行隐藏的设置／清空，也不触发隐藏项必选校验。重新显示恢复本次操作及临时选择，显示后的设置仍需选具体 ID。前后端须对齐此语义，不能仅隐藏控件而继续发送修改操作。
- 沿用既有修改权限、可编辑状态及结果反馈，不增加修改已完成或不可编辑任务的权限。

### 5. 任务保存与提交

保存契约：

任务只新增以下两个逻辑字段，与现有结构对齐；任务保存、导入、批量修改接口均不提交名称，不新增名称字段或快照。

| 我方任务字段 | 含义 | 类型与空值 |
|---|---|---|
| `sensitiveLibraryId` | 敏感词库 ID | 可空，前后端交互使用完整字符串 |
| `replaceLibraryId` | 替换词库 ID | 可空，前后端交互使用完整字符串 |

1. 设置／更换只保存对应类型的 ID，清空只将对应 ID 置为 `null`；另一类不变。名称仅供本次查询展示，不记录或比较历史名称。
2. 实际 ID 已超出 JavaScript 安全整数范围，前端不得转为 `Number`；后端使用精确字符串或 64 位整数存储，不经浮点转换。LinkFox 出站类型见第 6 节。
3. 未选择统一为 `null`，不用 `0`、空字符串、空数组或字符串 `"null"`。历史任务缺字段按未选择处理，不回刷或自动补选；仅编辑其他字段时保留原词库配置。
4. 不加入“记住上次配置”等个人默认配置。隐藏时按第 1、3、4 节保留 ID 或操作语义，不将未渲染字段序列化为空。

保存与提交规则：

| 操作 | 处理规则 |
|---|---|
| 保存为待提交 | 沿用既有保存校验，不触发生图；允许保留当前不可选的 ID。 |
| 保存并提交、列表直接提交、批量提交 | 沿用既有额度及其他校验；确认弹窗不加词库校验项，不为提交额外查询列表或逐任务查询，不新增词库可用性拦截。 |
| LinkFox 出站 | 直接使用任务保存的 ID，由 LinkFox 校验；未选择则省略对应字段。用户更换／清空并保存后使用新配置。 |
| 未启用 LinkFox／其他模型请求 | 未启用时不调用 LinkFox；其他模型请求始终排除两个词库字段，任务仍可保留 ID。 |

上述规则适用于加载中、加载失败、分页未完整、有效空列表及完整列表缺少原 ID 等状态；列表仅用于选择、名称展示和提示，不作为生图接口调用结果。批量修改“设置但未选”的表单校验仍按第 4 节执行。调用失败不得自动删除 ID 或去掉词库参数重试，按第 5.1 节处理。

### 5.1 接口失败与复制重跑

1. 沿用既有失败状态：单模型全部失败进入“已完成”，原任务不恢复编辑；多模型沿用各模型结果及整体状态判定，不因 LinkFox 失败将其他模型一并判失败。
2. 在“已完成”点击现有“复制重跑”，在“建任务”创建新任务，逐项继承来源的完整 `sensitiveLibraryId`、`replaceLibraryId`；空值或历史缺字段仍为空。复制不查询名称或复制列表，不因 ID 当前不可选、查询失败或未启用 LinkFox 而丢弃配置。
3. 复制不自动提交或修复 ID。打开新任务时按第 1、2 节决定显示、查询及回显；用户可更换／清空后保存提交，只影响新任务。未经处理原样重提可能再次失败。
4. 仅明确识别为词库参数错误时，在既有失败原因位置补充：“词库不可用，请复制重跑后，在新任务中更换或清空对应词库，再重新提交。”保留实际错误信息；其他错误沿用原原因，不凭列表缺失或任意接口错误推断词库问题。具体错误码及内容待联调核对。
5. 两端均适用；已有批量复制如共用此流程，按各来源任务独立继承，不串用 ID。不新增批量复制入口，其他复制信息、权限及状态沿用既有流程。

### 6. LinkFox 接口对接

查询词库：

使用现有调用通道发送 `POST /linkfox-ai/image/v2/material/list`，JSON 参数如下；自动分页和异常展示统一按第 2 节。

| 参数 | 类型与取值 |
|---|---|
| `type` | 字符串：敏感词库 `"11"`，替换词库 `"12"` |
| `pageNum` | 数字，起始 `1` |
| `pageSize` | 数字，固定 `100` |

```json
{
  "type": "11",
  "pageNum": 1,
  "pageSize": 100
}
```

已核对的代理通道有两层业务包装：

| 内容 | 实际路径与类型 |
|---|---|
| 代理业务成功 | 根层 `code` 为字符串 `"0"` |
| LinkFox 业务成功 | `data.code` 为数字 `200` |
| 列表 | `data.data.list`，数组 |
| 主键、名称 | `data.data.list[].id`、`.name`，字符串 |
| 总数 | `data.data.total`，数字 |
| 是否还有下一页 | `data.data.hasMore`，布尔值 |

HTTP 成功不等于业务成功，两层状态及结构均需有效；按实际通道解析，不能将官方示例的 `data.list` 直接用于上述代理。有效空数组与异常区分，列表缺失、`null` 或类型错误按加载失败。文档将 `hasMore` 标作 number，但示例及实测为布尔值，需核对实际通道解析。

提交商品套图：

`POST /linkfox-ai/image/v4/make/productMarketMaterial` 的 JSON 顶层增加以下映射；提交时机及校验边界见第 5 节。

| LinkFox 入参 | 来源 | 文档类型与序列化 |
|---|---|---|
| `sensitiveLibraryId` | 任务保存的敏感词库 ID，来源类型 `11` | 可选单值 `Long`，精确序列化；为空省略 |
| `replaceLibraryId` | 任务保存的替换词库 ID，来源类型 `12` | 可选单值 `Long`，精确序列化；为空省略 |

两个参数可都不传、仅传一个或同时各传一个；不传名称。前后端使用字符串不代表 LinkFox 已验证接受带引号 ID，上游兼容性尚未实测。

按官方文档：敏感词库命中后进行 AI 改写规避，替换词库按预设映射替换；同时使用时先改写、再替换，替换不以敏感词命中或 AI 改写成功为前提。不存在、无权访问或类型不匹配的 ID 返回参数校验错误，后续处理见第 5.1 节。以上生图行为尚未实测，不能用接口受理成功代替最终效果验收。

### 7. 权限、兼容与上线依赖

1. 沿用各入口及复制重跑既有权限、当前 LinkFox 授权范围，不信任跨类型或跨授权范围的 ID；不得因此新增第 5 节已排除的提交前列表查询。
2. 新字段允许为空，旧调用方未传时保持原有生图行为；其他模型的接口映射与生成规则不变。
3. 既有 V4 调用链及各入口子模型显示条件等核对项，统一见文末“接入联调待核对”。
4. 前后端对齐保存、回显、批量修改、复制继承和出站映射，更新我方接口文档后完成联调。

## 风险描述

| 风险 | 对应处理与限制 |
|---|---|
| 查询失败或分页不完整 | 第 2 节统一加载失败、保留 ID、支持重试；不使用部分列表判定缺失。 |
| 已保存词库被删除或调整权限 | 按第 2 节区分列表缺失与查询异常，不新增词库提交拦截；上游拒绝后走既有失败流程。名称及词条版本不留存。 |
| 复制后仍使用无效 ID | 复制不会修复 ID，需在新任务更换或清空，原样重提可能再次失败。 |
| ID 精度或代理包装解析错误 | 按第 5、6 节核对全链路精度及两层业务状态。 |
| 生图行为未联调 | 在获准环境验证组合、错误处理及实际生成效果，记录无法确认的情况。 |

## 验收标准

以下 20 项均需覆盖美工版、运营版的适用场景。四个可配置入口验证只存 ID 及后续出站请求，查看验证只读回显，复制重跑验证独立继承；文案及细则以对应章节为准。

| 编号 | 验收场景 | 预期结果 |
|---:|---|---|
| 1 | 两端打开新增、编辑、导入、批量修改，满足显示条件 | 各入口的默认值、位置、样式和操作符合第 1 节。 |
| 2 | 不选、仅敏感、仅替换、两者同时使用 | 各单选，只存 ID；LinkFox 传已选 ID、省略空值，其他模型不带参数。 |
| 3 | 大整数、同类同名、空词库候选 | ID 不丢精度，同名可按 ID 区分，不按名称合并或过滤空词库。 |
| 4 | 单／多页、有效空列表、网络／业务／结构异常、后续页失败、总数不完整 | 按第 2 节每页 100 自动取齐后展示；空列表与失败区分，异常保留 ID、不展示部分结果，重试仅影响该类型。 |
| 5 | 编辑更换／清空一类，再打开 | 仅对应 ID 更新／置空；重开按当前列表回显，查询不修改配置（第 2、5 节）。 |

| 7 | 批量设置一类、另一类保持，再测清空及仅改其他字段 | 设置／保持／清空结果符合第 4 节，各任务不串值；显示时设置未选阻止修改。 |
| 8 | 历史任务、旧调用方、仅其他模型、不同授权上下文 | 缺字段保持原行为，不自动补选；不改变其他模型请求，不串用候选项或越权修改。 |

| 10 | 后续获准生图联调：敏感词、替换词及组合命中 | 改写、替换及组合执行符合第 6 节；核对实际效果，记录未确认项。 |

| 12 | 长名称、同类重名；候选项、已选项及查看 | 长名称可通过鼠标／键盘查看完整名称与 ID，同名按 ID 区分并正确保存；详情浮层的触发、关闭及适用状态符合第 1 节。 |

| 20 | 批量先设置／清空再隐藏，含设置未选；导入先选后隐藏 | 批量隐藏提交均保持、不校验隐藏项，再显示恢复草稿且设置需选；导入隐藏仍统一保存本次选择。 |

## 原型使用说明

以下仅说明评审工具；字段交互按第 1～4 节执行，实际业务按实时查询结果回显。

- 静态样例：每类 4 条，普通名称 1 条、长名称 1 条、同名不同 ID 2 条；特殊样例名称前置“【演示】长名称…”或“【演示】同名…”。仅精简演示数据，实际列表仍完整展示。
- 默认演示：新增／导入两项未选、正常列表；批量修改两项保持不变、正常列表。编辑／查看使用预置的两个 ID，默认演示均不在列表；该异常仅这两个场景提供，排第一，正常列表排第二。有 ID 时默认异常，无 ID 时保持未选且异常选项禁用；更换或清空后退出异常演示，沿用本次列表。
- 演示控件：顶部切换五个场景；模型控件提供仅 LinkFox、混合、未启用三种状态，批量不定义新的混选判断。查询状态控件随区域显隐，批量修改仅“设置词库”项显示、查看仅有 ID 项显示；关闭预览隐藏全部左侧控件，重开恢复适用控件。计数按每类一次模拟查询计，不代表真实分页请求数。
